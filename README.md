# Presentación: Modelos de Negocios Bioeconómicos en Territorios Rurales

Este paquete contiene todos los materiales para la presentación en el evento "Territorios que inspiran: Retos y Oportunidades de la Bioeconomía en Antioquia" (25 de noviembre, 2025).

## Contenido

### 1. `bioeconomia_territorios_gamma.html` 
**Presentación principal en formato reveal.js**

- **Cómo usar:** 
  - Abrir el archivo directamente en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari)
  - La presentación se carga automáticamente
  - **Navegación:**
    - Flechas del teclado: ← → para avanzar/retroceder
    - Espacio: avanzar
    - Esc: vista general de todas las diapositivas
    - F: pantalla completa
  
- **Características:**
  - 14 diapositivas diseñadas para 12 minutos
  - Estructura SCQA/SCR (Situación-Complicación-Pregunta-Resolución)
  - Diseño profesional con colores institucionales
  - Compatible con proyectores estándar (16:9)
  - No requiere conexión a internet (todos los estilos están en CDN pero se cargan al inicio)

- **Recomendación:** Probar la presentación en el equipo y proyector del evento 15 minutos antes de la sesión.

---

### 2. `notas_presentador_bioeconomia.md`
**Guía detallada para el presentador**

- **Contenido:**
  - Distribución exacta del tiempo (12 minutos)
  - Mensajes clave para cada diapositiva
  - Transiciones sugeridas
  - Tips de lenguaje corporal y ritmo
  - Respuestas a preguntas frecuentes esperadas
  - Checklist pre-presentación

- **Cómo usar:**
  - Leer completo al menos una vez antes del evento
  - Imprimir para tener como referencia durante ensayos
  - Marcar las secciones donde se quiere poner énfasis especial
  - Cronometrar el ensayo con estas notas

- **Tiempo recomendado de preparación:** 2-3 ensayos completos

---

### 3. `resumen_ejecutivo_gamma.md`

## Conversión de Formatos (Opcional)

### Para convertir el resumen ejecutivo a PDF:

**Opción 1: Usando Pandoc (recomendado)**
```bash
pandoc resumen_ejecutivo_gamma.md -o resumen_ejecutivo_gamma.pdf --pdf-engine=xelatex
```

**Opción 2: Herramientas online**
- https://www.markdowntopdf.com/
- https://dillinger.io/ (con opción de exportar a PDF)

**Opción 3: Desde VS Code**
- Instalar extensión "Markdown PDF"
- Click derecho en el archivo → "Markdown PDF: Export (pdf)"

## Backup y Contingencias

### Si falla la conexión a internet:
- La presentación HTML debe funcionar offline
- Todos los estilos CSS están en CDN pero se cargan al inicio
- **Solución de emergencia:** Tener presentación en PDF como respaldo

### Si falla el proyector:
- Tener la presentación en dispositivo móvil/tablet
- Usar el resumen ejecutivo impreso como guía

### Si se reduce el tiempo:
- Priorizar diapositivas: 1, 2, 3-4 (juntas), 5-6 (resumir), 7-10 (elegir 2 casos), 12, 14
- Tiempo mínimo viable: 8 minutos
